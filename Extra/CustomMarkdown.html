Git Setup (Basic)

First of all download the suitable version of git from https://git-scm.com/downloads
Follow the instructions on the site and finish installing git

Filling Credentials

On Windows search and open the application called "Git Bash"
On linux, just open the terminal you use
Now write the following commands, you can keep the username anything you like but remember to set the email to the one you used to create your github account

$ git config --global user.name "John Doe" $ git config --global user.email johndoe@example.com

Time to Change your Editor

$ git config --global core.editor code

or

$ git config --global core.editor "/path/to/editor.exe"

Changing your Default Branch Name (Optional)

$ git config --global init.defaultBranch main

Initializing a Repository

Create a New folder or Open an existing folder where you want to create your repository
Right click the empty space in folder to open the context menu and select "Git Bash Here" for windows and "Open Terminal in this Folder" in Linux
Now type the following in the Terminal

$ git init

This will Initialize the repository for use

Creating and Adding Files

You can create files the normal way (right click > new > text document) and then later renaming it as index.html, create another file named readme.md, these files we created are untracked right now, we will have to add them to the staging area in order to proceed further.
open the git bash again and type

$ git add index.html

$ git add readme.md

or

$ git add -A

The former command adds files one by one to the staging area whereas the latter command adds all the files in the folder to staging area at once

Commiting Changes

Commiting changes means we are finalizing the files for uploading (for now). Only the staged files are committed. To commit changes in a easier way type

$ git commit -m "Any Commit Message"

Adding URL

$ git remote add origin url_here

Pulling a Repository

$ git pull origin main/master

Pushing a Repository

$ git push -u origin main/master
